# SourceJump Plugin

The new, unified SourceMod plugin for [SourceJump](https://sourcejump.net). It replaces the separate database, anti-cheat logs and world record plugins with a single plugin.

## Status

**Planning.** There is no code yet. We are deciding what the plugin should do before building it.

## Specification

The specification lives in **[docs/spec.md](docs/spec.md)**. It covers each part of the plugin, the open questions, and what has been agreed so far. It is the official record of decisions.

## Getting involved

- Join the discussion in the [#plugin-topics](https://discord.gg/RYP5G4tuwX) forum on the SourceJump Discord. Each spec section has its own topic.
- 👍 the messages you agree with. That's how we measure support.
- Missing a question, a whole topic, or think something is wrong? Say so in the topic, or in the [💡 Missing something?](https://discord.com/channels/333865962568941568/1557356307835650139) topic.
- Once a topic is settled, its outcome is written into the spec and added to the decision log.
